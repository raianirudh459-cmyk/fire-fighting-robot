# Confirmed web technology — no Node.js required

**VANARAKSHAK 2.0 front-end stack:** HTML5 + CSS3 + vanilla JavaScript (ES6+).
**Dependencies:** none. **Node.js/npm install:** not needed. **Build command:** none.

Get started:
1. Visit `web/index.html` from a browser.
2. Open `web/tests.html` to run the dependency-free browser tests.
3. Read `web/README.md` for a full simulator overview.
4. Use `docs/14_API_CONTRACT.md` when Saksham begins verified firmware integration.

The current web interface is fully a **SIMULATOR** and sends NO commands to motors, pump, or camera. Old Arduino Uno code elsewhere in the repository is not the 4WD firmware.
