## Suggested model labels
- **MANUAL** — Web remote driving
- **AUTO** — Supervised obstacle-avoidance demonstration
- **ENVIRONMENT** — Temperature, humidity and MQ135 air-quality sensor
- **VISION** — Optional camera if the module is verified
- **CAUTION** — Flame/obstacle status is illustrative and unverified for real wildfires
- **INNOVATION** — Mobile-first dashboard + modes
- **WATER SYSTEM** — Optional pump disabled until inspected
- **ECO-FRIENDLY** — Reused model materials
- **WILDLIFE** — Habitat and biodiversity awareness

## Safe demonstration sequence
1. Show mobile dashboard SIMULATOR badge before actual network is connected.
2. Explain the green/red status and the environmental readings.
3. If adult-supervised real robot is ready, demonstrate a short slow manual motion in enclosed indoor arena.
4. If firmware has passed fault and obstacle checks, show the short autonomous mode.
5. Point to the pump system as optional; use a simulated response by default.
6. Finish with wildlife awareness and engineering limitations.

No fire, smoke, heat, combustible substances or dangerous battery activities.
